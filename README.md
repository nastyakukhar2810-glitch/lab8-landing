# UkrMovych — лендинг

Лендинг тренажера української мови **UkrMovych** («+1 бал на НМТ за 20 секунд щодня»).
Проєкт створено в межах лабораторних робіт №7 та №8 з дисципліни «Технології веброзробки та дизайну».

## Технології

- HTML5 (семантична верстка)
- Tailwind CSS (CDN) + власні стилі `custom-styles.css`
- Font Awesome, Google Fonts (Inter)
- Git, GitHub, GitHub Pages, Netlify

## Структура проєкту

```
lab8-landing/
├── index.html
├── custom-styles.css
├── assets/
│   ├── images/   (hero.png, logo.png)
│   └── icons/    (icon-words.png, icon-repeat.png, icon-trainers.png)
└── README.md
```

## Запуск локально

```bash
git clone https://github.com/nastyakukhar2810-glitch/lab8-landing.git
cd lab8-landing
```

Відкрити `index.html` у браузері (або через розширення Live Server у VS Code).
